# 24장 축전기와 유전체

> 대응 교재: Halliday 12판 25장 · Young&Freedman 15판 24장
> 축전기는 전하와 에너지를 전기장의 형태로 저장하는 소자다. 카메라 플래시, 제세동기, 전원 회로의 평활, 메모리 소자, 터치스크린, 가속도 센서가 모두 축전기를 쓴다. 이 장은 22장(가우스 법칙)과 23장(전위)을 실제 소자에 적용하는 장이다. 또 처음으로 **물질 속의 전기장**을 다룬다. 절연체를 넣으면 왜 전기용량이 커지는지를 분자 수준에서 이해하는 것이 이 장의 두 번째 목표다.

## 학습 목표
- "전하 가정 → 가우스 법칙으로 $\vec{E}$ → 적분으로 $V$ → $C = Q/V$"의 절차로 평행판·원통·구 축전기의 전기용량을 유도할 수 있다.
- 직렬·병렬 연결의 등가 전기용량을 유도하고, 축전기 회로에서 각 축전기의 전하와 전압을 구할 수 있다.
- 축전기에 저장된 에너지 $U = Q^2/2C$를 일의 적분으로 유도하고, 에너지 밀도 $u = \frac{1}{2}\varepsilon_0E^2$을 해석할 수 있다.
- 유전체를 넣을 때 전지를 연결한 경우와 끊은 경우의 $Q$, $V$, $U$ 변화를 구할 수 있다.
- 분극, 속박 전하, 전기 감수율로 유전 상수를 미시적으로 설명할 수 있다.

## 고등학교 물리와 무엇이 다른가
고등학교에서는 $C = \varepsilon A/d$와 $U = \frac{1}{2}CV^2$을 주어진 공식으로 썼다. 대학에서는 이 식들을 **유도**한다. 평행판뿐 아니라 동축 케이블, 구형 축전기, 유전 상수가 위치에 따라 변하는 축전기까지 같은 방법으로 다룬다. 에너지도 "축전기의 에너지"가 아니라 **전기장에 저장된 에너지**라는 관점으로 바뀐다. 이 관점은 31장 전자기파가 에너지를 나른다는 생각으로 이어진다. 유전체는 고등학교에서 "유전율이 큰 물질"로만 배웠지만, 여기서는 분자가 전기 쌍극자가 되어 장을 약하게 만든다는 미시적 그림과, 그것을 정량적으로 표현하는 분극 벡터 $\vec{P}$를 배운다.

## 24.1 전기용량

### 정의
절연된 두 도체에 크기가 같고 부호가 반대인 전하 $+Q$, $-Q$를 주면 두 도체 사이에 전위차 $V$가 생긴다. 장은 전하에 비례하고(중첩 원리), 전위차는 장의 적분이므로 $V$도 $Q$에 비례한다. 그 비례 상수가 **전기용량**(capacitance)이다.
$$
\boxed{C = \frac{Q}{V}}
$$
단위는 **패럿(farad)** $\text{F} = \text{C/V}$이다. 여기서 $Q$는 한 도체의 전하의 **크기**, $V$는 두 도체 사이 전위차의 **크기**이므로 $C > 0$이다. $C$는 $Q$나 $V$에 의존하지 않고 **도체의 모양과 배치, 사이를 채운 물질**에만 의존한다. 이런 두 도체를 **축전기**(capacitor)라 한다.

### 전기용량을 구하는 표준 절차
1. 두 도체에 $\pm Q$가 있다고 가정한다.
2. 가우스 법칙으로 두 도체 사이의 $\vec{E}$를 구한다.
3. $V = \left|\int_-^+\vec{E}\cdot d\vec{\ell}\right|$로 전위차를 구한다.
4. $C = Q/V$. $Q$가 약분되어 사라져야 한다.

### 평행판 축전기
넓이 $A$인 두 판이 간격 $d$로 마주 보고 있다($d \ll \sqrt{A}$, 가장자리 효과 무시). 22장 예제 22.8에서 두 판 사이의 장은 $E = \sigma/\varepsilon_0 = Q/\varepsilon_0A$로 균일하다. 따라서 $V = Ed = Qd/\varepsilon_0A$이고
$$
\boxed{C = \frac{\varepsilon_0A}{d}}
$$
넓을수록, 가까울수록 용량이 크다.

### 원통형 축전기(동축)
반지름 $a$인 도체 원통과 반지름 $b$인 동축 원통 껍질, 길이 $L$($L\gg b$). 안쪽에 $+Q$($\lambda = Q/L$)를 주면 사이의 장은 $E = \lambda/2\pi\varepsilon_0r$이다.
$$
V = \int_a^b\frac{\lambda}{2\pi\varepsilon_0r}dr = \frac{Q}{2\pi\varepsilon_0L}\ln\frac{b}{a}\quad\Longrightarrow\quad \boxed{C = \frac{2\pi\varepsilon_0L}{\ln(b/a)}}
$$

### 구형 축전기와 고립된 구
반지름 $a$인 도체 구와 반지름 $b$인 동심 도체 구 껍질. 사이의 장은 $kQ/r^2$이다.
$$
V = kQ\left(\frac{1}{a} - \frac{1}{b}\right)\quad\Longrightarrow\quad \boxed{C = 4\pi\varepsilon_0\frac{ab}{b - a}}
$$
$b\to\infty$이면 **고립된 도체 구**의 전기용량 $C = 4\pi\varepsilon_0a$를 얻는다. 이때 "다른 쪽 도체"는 무한히 먼 곳이다. 지구($a = 6.37\times10^6\ \text{m}$)조차 $C = 7.1\times10^{-4}\ \text{F}$, 즉 1 mF도 안 된다.

### 예제 24.1 1 F짜리 평행판 축전기
간격이 $1.0\ \text{mm}$인 진공 평행판 축전기로 $1.0\ \text{F}$를 만들려면 판의 넓이가 얼마나 되어야 하는가?

**풀이**
$$
A = \frac{Cd}{\varepsilon_0} = \frac{(1.0)(1.0\times10^{-3})}{8.85\times10^{-12}} = 1.1\times10^8\ \text{m}^2
$$
한 변이 약 $11\ \text{km}$인 정사각형이다. 1 F는 엄청나게 큰 용량이라 보통의 축전기는 pF~μF 범위다. 그런데 손바닥만 한 **슈퍼커패시터**는 수백~수천 F에 이른다. 어떻게 가능한지는 24.5절의 🔬에서 본다. 답은 $C = \varepsilon A/d$의 $d$를 나노미터로, $A$를 수천 $\text{m}^2$로 만드는 것이다.

### 예제 24.2 동축 케이블의 단위 길이당 전기용량과 평행판 극한
(가) 안 도체의 반지름이 $a = 0.50\ \text{mm}$, 바깥 도체의 안 반지름이 $b = 2.0\ \text{mm}$인 진공 동축 케이블의 단위 길이당 전기용량을 구하라. (나) 구형 축전기의 공식에서 $b = a + d$, $d\ll a$로 두면 평행판 공식이 나옴을 보여라.

**풀이**
(가)
$$
\frac{C}{L} = \frac{2\pi\varepsilon_0}{\ln(b/a)} = \frac{2\pi(8.85\times10^{-12})}{\ln4} = 4.0\times10^{-11}\ \text{F/m} = 40\ \text{pF/m}
$$
실제 케이블은 두 도체 사이를 폴리에틸렌($\kappa\approx2.3$) 같은 유전체로 채워 이보다 약 2.3배 크다(24.4절). 신호가 긴 케이블을 지날 때 이 용량을 충전해야 하므로 고속 신호가 무뎌진다.

(나)
$$
C = 4\pi\varepsilon_0\frac{a(a + d)}{d} \approx \frac{\varepsilon_0(4\pi a^2)}{d}
$$
구면의 넓이 $4\pi a^2$를 $A$로 보면 평행판 공식이다. 간격이 곡률 반지름보다 훨씬 작으면 휘어진 판도 평평한 판처럼 행동한다. 원통형에서도 $\ln(1 + d/a)\approx d/a$로 같은 결과가 나온다.

## 24.2 축전기의 연결

### 병렬 연결
축전기 여러 개의 양끝을 각각 묶으면 모든 축전기의 **전압이 같다**. 전하는 각자 $Q_i = C_iV$이고, 전체 전하는 그 합이다.
$$
Q = \sum_iC_iV\quad\Longrightarrow\quad \boxed{C_{\text{eq}} = C_1 + C_2 + \cdots}
$$
판의 넓이를 늘린 것과 같다.

### 직렬 연결
축전기를 한 줄로 이으면 **각 축전기의 전하가 같다**. 전지가 맨 바깥 두 판에 $\pm Q$를 줄 때, 축전기 사이를 잇는 도선과 두 판은 회로의 나머지와 고립되어 있어 알짜 전하가 0으로 유지된다. 따라서 한쪽 판에 $-Q$가 유도되면 다른 쪽 판에는 $+Q$가 나타난다. 전압은 더해진다.
$$
V = \sum_i\frac{Q}{C_i}\quad\Longrightarrow\quad \boxed{\frac{1}{C_{\text{eq}}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots}
$$
간격을 늘린 것과 같으므로 등가 용량은 가장 작은 용량보다도 작다.

> **💡 개념 확인: 저항과 거꾸로**
> 축전기의 병렬은 "더하기", 직렬은 "역수의 합"이다. 25장의 저항은 정반대다. 헷갈리면 평행판 그림을 떠올린다. 병렬은 판이 넓어지는 것($C\propto A$), 직렬은 간격이 길어지는 것($C\propto1/d$)이다. 저항은 길이에 비례하고 단면적에 반비례하므로($R\propto L/A$) 반대가 된다.

### 예제 24.3 축전기 회로
$C_2 = 4.0\ \mu\text{F}$와 $C_3 = 8.0\ \mu\text{F}$를 병렬로 묶고, 이것을 $C_1 = 12\ \mu\text{F}$와 직렬로 연결해 $12\ \text{V}$ 전지에 연결했다. 등가 용량과 각 축전기의 전하·전압을 구하라.

**풀이**
$C_{23} = 4.0 + 8.0 = 12\ \mu\text{F}$. $C_1$과 $C_{23}$의 직렬은 $C_{\text{eq}} = \dfrac{(12)(12)}{12 + 12} = 6.0\ \mu\text{F}$.
전체 전하 $Q = C_{\text{eq}}V = (6.0\ \mu\text{F})(12\ \text{V}) = 72\ \mu\text{C}$. 직렬이므로 $Q_1 = 72\ \mu\text{C}$, $V_1 = Q_1/C_1 = 6.0\ \text{V}$이고, 나머지 $V_{23} = 6.0\ \text{V}$가 병렬부에 걸린다. $Q_2 = (4.0)(6.0) = 24\ \mu\text{C}$, $Q_3 = (8.0)(6.0) = 48\ \mu\text{C}$. 검산: $Q_2 + Q_3 = 72\ \mu\text{C} = Q_1$.

## 24.3 전기장에 저장된 에너지

### 충전하는 데 드는 일
축전기에 이미 전하 $q$가 있어 전위차가 $v = q/C$일 때, 작은 전하 $dq$를 음극판에서 양극판으로 옮기는 데 드는 일은 $dW = v\,dq = (q/C)\,dq$이다. $0$에서 $Q$까지 적분하면
$$
\boxed{U = \int_0^Q\frac{q}{C}dq = \frac{Q^2}{2C} = \frac{1}{2}CV^2 = \frac{1}{2}QV}
$$
$\frac{1}{2}$이 붙는 이유는 충전하는 동안 전위차가 $0$에서 $V$까지 선형으로 커지므로 평균 전위차가 $V/2$이기 때문이다.

### 에너지 밀도
평행판 축전기에서 $U = \frac{1}{2}CV^2 = \frac{1}{2}\dfrac{\varepsilon_0A}{d}(Ed)^2 = \frac{1}{2}\varepsilon_0E^2\cdot(Ad)$이다. $Ad$는 장이 있는 공간의 부피이므로, 단위 부피당 에너지는
$$
\boxed{u = \frac{1}{2}\varepsilon_0E^2}
$$
이다. 평행판에서 유도했지만 이 식은 **일반적으로 성립**한다. 에너지가 전하에 있다고 보든 장에 있다고 보든 정전기학에서는 같은 답을 주지만, 전자기파(31장)처럼 전하 없이 장만 있는 경우에는 장에 에너지가 있다고 보아야만 한다. 예제 24.5에서 구형 축전기로 확인한다.

### 예제 24.4 충전된 축전기를 빈 축전기에 연결하기
$C_1 = 4.0\ \mu\text{F}$를 $100\ \text{V}$로 충전한 뒤 전지를 떼고, 충전되지 않은 $C_2 = 6.0\ \mu\text{F}$에 병렬로(같은 부호 판끼리) 연결했다. 나중 전압과, 연결 전후의 에너지를 구하라.

**풀이**
전하 보존: $Q = C_1V_0 = 400\ \mu\text{C}$가 두 축전기에 나뉜다. 병렬이므로 $V_f = Q/(C_1 + C_2) = 40\ \text{V}$.
$$
U_i = \frac{1}{2}(4.0\times10^{-6})(100)^2 = 0.020\ \text{J}, \qquad U_f = \frac{1}{2}(10\times10^{-6})(40)^2 = 0.0080\ \text{J}
$$
에너지의 60%가 사라졌다. 연결하는 도선의 저항이 아무리 작아도 이 손실은 같다. 저항이 작으면 큰 전류가 짧게 흘러 같은 열이 나고, 저항이 0에 가까워지면 회로의 인덕턴스와 전자기 복사가 에너지를 가져간다. 충돌로 비유하면 이것은 **완전 비탄성 충돌**과 같다(9장). 전하(운동량)는 보존되지만 에너지는 보존되지 않는다. 일반적으로 손실은 $\dfrac{1}{2}\dfrac{C_1C_2}{C_1 + C_2}V_0^2$이다.

### 예제 24.5 구형 축전기의 장 에너지
구형 축전기의 장 에너지 $\int u\,dV$를 직접 적분해 $Q^2/2C$와 같음을 보여라. 고립된 도체 구($b\to\infty$)의 에너지는?

**풀이**
$a < r < b$에서 $E = kQ/r^2$이다. 두께 $dr$인 구 껍질의 부피 $4\pi r^2dr$를 쓰면
$$
U = \int_a^b\frac{1}{2}\varepsilon_0\left(\frac{kQ}{r^2}\right)^24\pi r^2dr = \frac{kQ^2}{2}\int_a^b\frac{dr}{r^2} = \frac{kQ^2}{2}\left(\frac{1}{a} - \frac{1}{b}\right)
$$
$C = ab/[k(b - a)]$이므로 $Q^2/2C = \frac{kQ^2}{2}\cdot\frac{b - a}{ab}$로 정확히 같다. $b\to\infty$이면 $U = kQ^2/2a$이다. 같은 전하를 구 전체에 고르게 채웠을 때의 $\frac{3}{5}kQ^2/a$(23장 연습문제 13)보다 작다. 도체에서는 전하가 서로 최대한 멀리, 즉 표면으로 퍼져서 에너지가 가장 낮은 배치를 이루기 때문이다.

### 극판 사이의 힘
고립된(전하 $Q$ 일정) 평행판 축전기의 간격을 $x$라 하면 $U = Q^2x/2\varepsilon_0A$이다. 판 사이의 힘은 가상 일의 원리로
$$
F = -\frac{dU}{dx} = -\frac{Q^2}{2\varepsilon_0A}
$$
음수이므로 인력이다. 크기는 $Q\cdot\dfrac{\sigma}{2\varepsilon_0}$로, 한 판이 받는 장은 두 판 사이 장 $\sigma/\varepsilon_0$이 아니라 **다른 판이 만든 장** $\sigma/2\varepsilon_0$이다(22장 연습문제 12). 넓이 $0.010\ \text{m}^2$, 간격 $1.0\ \text{mm}$, $1000\ \text{V}$이면 $F = \varepsilon_0AV^2/2d^2 = 0.044\ \text{N}$이다. 작은 힘 같지만 간격 마이크로미터 수준의 MEMS 소자에서는 $1/d^2$ 때문에 매우 커져서, 이 힘으로 미세 거울이나 스위치를 구동한다(🔗 아래).

## 24.4 유전체

### 실험 사실
축전기의 두 판 사이를 절연체로 채우면 전기용량이 일정한 비율로 커진다.
$$
C = \kappa C_0
$$
$\kappa$($\geq1$)를 **유전 상수(dielectric constant)** 또는 비유전율, 그 절연체를 **유전체**(dielectric)라 한다. $\varepsilon = \kappa\varepsilon_0$를 그 물질의 **유전율**(permittivity)이라 한다.

| 물질 | 유전 상수 $\kappa$ | 절연 강도 (MV/m) |
|---|---|---|
| 진공 | 1 (정확) | — |
| 공기 (1 atm) | 1.00054 | 3 |
| 폴리스타이렌 | 2.6 | 24 |
| 종이 | 3.5 | 16 |
| 파이렉스 유리 | 4.7 | 14 |
| 규소 | 11.7 | — |
| 물 (20 °C) | 80.4 | — |
| 티탄산스트론튬 | 310 | 8 |

(실온 근처의 대표값이다. 절연 강도는 시료의 두께와 상태에 따라 크게 달라진다.)

유전체는 두 가지 이점이 있다. 용량을 $\kappa$배 키우고, 공기보다 절연 강도가 큰 물질을 쓰면 더 높은 전압을 견딘다.

### 전지를 연결한 경우와 끊은 경우
- **전지를 끊은 경우(Q 일정)**: $V = Q/C = V_0/\kappa$, $E = E_0/\kappa$, $U = Q^2/2C = U_0/\kappa$. 장과 에너지가 줄어든다.
- **전지를 연결한 경우(V 일정)**: $Q = \kappa Q_0$, $E = V/d = E_0$, $U = \frac{1}{2}CV^2 = \kappa U_0$. 전지가 추가 전하를 공급한다.

### 유전체 속의 가우스 법칙
유전체 속에서는 판 위의 **자유 전하(free charge)** 외에 유전체 표면에 **속박 전하**(bound charge)가 나타난다(24.5절). 선형 유전체에서는 속박 전하의 효과가 장을 $1/\kappa$로 줄이는 것으로 요약되므로, 가우스 법칙은
$$
\oint\kappa\vec{E}\cdot d\vec{A} = \frac{q_{\text{free,in}}}{\varepsilon_0}
$$
로 쓸 수 있다. 우변에는 속박 전하를 빼고 **자유 전하만** 넣는다. 예를 들어 유전체 속 점전하의 장은 $q/(4\pi\kappa\varepsilon_0r^2)$이다. 물($\kappa\approx80$) 속에서 이온 사이의 쿨롱 힘이 진공의 약 $1/80$로 약해지는 것이 소금이 물에 잘 녹는 주된 이유다(21장 🔗).

### 예제 24.6 유전체를 넣을 때의 에너지 출입
$C_0 = 2.0\ \text{nF}$인 공기 축전기를 $100\ \text{V}$로 충전했다. 판 사이를 $\kappa = 4.0$인 유전체 판으로 완전히 채운다. (가) 전지를 뗀 뒤 넣는 경우, (나) 전지를 연결한 채 넣는 경우에 대해 $Q$, $V$, $U$를 구하고 에너지 출입을 설명하라.

**풀이**
처음: $Q_0 = C_0V_0 = 200\ \text{nC}$, $U_0 = \frac{1}{2}C_0V_0^2 = 10\ \mu\text{J}$. 나중 용량 $C = \kappa C_0 = 8.0\ \text{nF}$.

(가) $Q = 200\ \text{nC}$ 일정. $V = Q/C = 25\ \text{V}$, $U = Q^2/2C = 2.5\ \mu\text{J}$. 에너지가 $7.5\ \mu\text{J}$ 줄었다. 유전체가 판 사이로 **빨려 들어가면서** 장이 그만큼 일을 했다. 유전체를 천천히 넣으려면 붙잡아야 하고, 붙잡는 손이 $7.5\ \mu\text{J}$를 받는다.

(나) $V = 100\ \text{V}$ 일정. $Q = CV = 800\ \text{nC}$, $U = \frac{1}{2}CV^2 = 40\ \mu\text{J}$. 전지는 추가 전하 $600\ \text{nC}$를 $100\ \text{V}$로 밀어 넣었으므로 $W_{\text{전지}} = (600\ \text{nC})(100\ \text{V}) = 60\ \mu\text{J}$의 일을 했다. 그중 $30\ \mu\text{J}$는 장 에너지 증가, 나머지 $30\ \mu\text{J}$는 유전체를 끌어당긴 역학적 일이다. 이 경우에도 유전체는 빨려 들어간다.

> **★ 심화: 유전체 판이 빨려 들어가는 힘 — 가장자리 장의 역할**
> 폭 $w$, 길이 $L$, 간격 $d$인 평행판 사이에 유전체 판이 길이 $x$만큼 들어가 있다. 두 부분은 병렬이므로
> $$C(x) = \frac{\varepsilon_0w}{d}\left[\kappa x + (L - x)\right] = \frac{\varepsilon_0w}{d}\left[L + (\kappa - 1)x\right]$$
> 이다. **전하가 일정**하면 $F = -\dfrac{\partial}{\partial x}\left(\dfrac{Q^2}{2C}\right) = \dfrac{Q^2}{2C^2}\dfrac{dC}{dx} = \dfrac{1}{2}V^2\dfrac{dC}{dx}$이다. **전압이 일정**하면 전지가 한 일 $V\,dQ = V^2dC$의 절반이 장 에너지로, 절반이 역학적 일로 가므로 $F = +\dfrac{1}{2}V^2\dfrac{dC}{dx}$로 같은 답이 나온다.
> $$F = \frac{(\kappa - 1)\varepsilon_0wV^2}{2d}$$
> 이 힘은 $x$에 무관하고, 유전체를 안으로 끌어들인다. 그런데 이상하다. 평행판 사이의 균일한 장은 판에 수직이므로, 유전체의 쌍극자들은 수직 방향의 힘만 받아야 한다. 판과 나란한 방향의 힘은 어디서 오는가? 답은 판의 **가장자리 장**(fringing field)이다. 가장자리에서 휘어져 나오는 장은 판과 나란한 성분을 가지고, 장의 세기가 판 안쪽으로 갈수록 커지므로 유전체의 유도 쌍극자를 강한 장 쪽으로 당긴다($\vec{F} = (\vec{p}\cdot\nabla)\vec{E}$). 에너지 방법은 이 복잡한 가장자리 장을 몰라도 정확한 답을 준다. 가상 일의 원리가 강력한 이유다.

### 예제 24.7 유전체가 일부만 채워진 축전기
넓이 $A$, 간격 $d$인 평행판 사이에 두께 $t$($< d$), 유전 상수 $\kappa$인 판이 판과 나란히 들어 있다. 전기용량을 구하라. $\kappa\to\infty$와 $t\to d$의 극한을 확인하라.

**풀이**
판에 $\pm Q$를 준다. 자유 전하는 판에만 있으므로 판과 나란한 어느 면에서나 가우스 법칙의 우변은 같다. 공기층에서 $E_0 = Q/\varepsilon_0A$, 유전체 속에서 $E = E_0/\kappa$이다. 전위차는
$$
V = E_0(d - t) + \frac{E_0}{\kappa}t = \frac{Q}{\varepsilon_0A}\left(d - t + \frac{t}{\kappa}\right)\quad\Longrightarrow\quad C = \frac{\varepsilon_0A}{d - t + t/\kappa}
$$
유전체가 판 사이의 어디에 있든 결과는 같다. 공기층과 유전체층의 **직렬 연결**로 보아도 같은 답이 나온다. $t\to d$이면 $C = \kappa\varepsilon_0A/d$이다. $\kappa\to\infty$이면 $C = \varepsilon_0A/(d - t)$로, 두께 $t$인 **도체 판**을 넣은 것과 같다. 도체는 "$\kappa = \infty$인 유전체"처럼 행동한다(내부 장 0).

> **★ 심화: 전기 변위 $\vec{D}$와 경계 조건**
> 유전체 문제를 체계적으로 다루기 위해 **전기 변위**(electric displacement)를 $\vec{D} = \varepsilon_0\vec{E} + \vec{P}$로 정의한다($\vec{P}$는 24.5절의 분극). 선형 등방 유전체에서는 $\vec{D} = \kappa\varepsilon_0\vec{E} = \varepsilon\vec{E}$이다. 가우스 법칙은
> $$\oint\vec{D}\cdot d\vec{A} = q_{\text{free,in}}, \qquad \nabla\cdot\vec{D} = \rho_{\text{free}}$$
> 가 되어, 속박 전하를 몰라도 $\vec{D}$를 구할 수 있다. 두 유전체의 경계면(자유 전하 없음)에서는 필박스와 직사각형 고리로 다음 **경계 조건**을 얻는다.
> - $\vec{D}$의 수직 성분이 연속: $\kappa_1E_{1\perp} = \kappa_2E_{2\perp}$ (예제 24.7)
> - $\vec{E}$의 나란한 성분이 연속: $E_{1\parallel} = E_{2\parallel}$ ($\oint\vec{E}\cdot d\vec{\ell} = 0$에서. 연습문제 11)
>
> 두 식에서 전기력선이 경계에서 꺾이는 각의 관계 $\tan\theta_1/\tan\theta_2 = \kappa_1/\kappa_2$가 나온다. 빛의 굴절(32장)과 비슷한 구조다.

> **🔗 전공 연결: 정전용량형 센서와 MEMS(기계공학)**
> $C = \varepsilon A/d$에서 $A$, $d$, $\varepsilon$ 중 하나라도 변하면 $C$가 변한다. 이것을 전기 신호로 읽는 것이 **정전용량형 센서**(capacitive sensor)다.
> - **간격 변화**: 스마트폰과 자동차 에어백의 **MEMS 가속도계**는 실리콘 칩 위에 용수철에 매달린 작은 질량과 빗살 모양 전극을 만든다. 가속되면 질량이 밀려 전극 간격이 바뀌고, $\Delta C/C\approx-\Delta d/d$를 측정한다(연습문제 12). 압력 센서와 정밀 변위 센서도 같은 원리다.
> - **넓이 변화**: 회전 각도 센서, 가변 축전기.
> - **유전율 변화**: 곡물이나 토양의 수분 센서. 물의 $\kappa\approx80$이 다른 물질보다 훨씬 커서 수분 함량에 민감하다. 액체 탱크의 수위계도 이 원리로 만든다.
>
> 메카트로닉스와 계측 과목에서 이 센서들의 회로(브리지, 교류 측정)를 배운다. 거꾸로 전압을 걸어 극판 사이 힘($\propto V^2/d^2$)으로 미세 구조를 움직이는 **정전 구동기**(electrostatic actuator)는 프로젝터의 미세 거울 배열 등에 쓰인다.

> **🔗 전공 연결: 터치스크린**
> 스마트폰의 **투영 정전용량 방식(projected capacitive)** 터치스크린은 유리 아래에 투명 전극(산화인듐주석 등)을 가로·세로 격자로 깔고, 교차점마다 두 전극 사이의 상호 전기용량을 계속 측정한다. 손가락은 수분이 많은 도체이므로 가까이 오면 전극에서 나온 전기력선 일부를 가로채 교차점의 용량을 바꾼다. 어느 교차점의 용량이 변했는지로 위치를 알아내고, 여러 교차점을 동시에 읽어 멀티터치를 구현한다. 절연체인 일반 장갑을 끼면 반응하지 않고, 손끝에 도전성 실을 넣은 장갑은 반응하는 이유가 이것이다.

## 24.5 유전체의 미시적 이해

### 분극
전기장 속에서 분자는 두 가지 방법으로 전기 쌍극자가 된다.
- **유도 쌍극자**: 극성이 없는 분자(예: $\text{N}_2$, $\text{CH}_4$)도 장이 전자 구름을 원자핵 반대쪽으로 조금 밀어 쌍극자가 된다. 약한 장에서는 $\vec{p} = \alpha\vec{E}$이며 $\alpha$를 **분극률**(polarizability)이라 한다.
- **영구 쌍극자의 정렬**: 물처럼 원래 쌍극자 모멘트를 가진 **극성 분자**(polar molecule)는 평소에 열운동으로 방향이 무질서하다가, 장이 걸리면 장 방향으로 부분적으로 정렬한다(21장 쌍극자의 토크와 퍼텐셜 에너지 $-\vec{p}\cdot\vec{E}$). 정렬 정도는 $pE$와 $k_BT$의 경쟁으로 정해지므로, 극성 액체의 유전 상수는 온도가 올라가면 작아진다. 물의 큰 $\kappa$는 이 정렬에서 온다.

어느 경우든 결과는 단위 부피당 쌍극자 모멘트, 즉 **분극(polarization)** 벡터
$$
\vec{P} = n\langle\vec{p}\rangle\qquad(\text{단위: C/m}^2)
$$
로 요약된다($n$은 분자 수 밀도). 대부분의 물질에서 약한 장에 대해 $\vec{P} = \chi_e\varepsilon_0\vec{E}$이다. $\chi_e$를 **전기 감수율**(electric susceptibility)이라 한다.

### 속박 전하와 장의 약화
고르게 분극된 유전체 판을 생각하자. 판 내부에서는 이웃 쌍극자의 $+$ 끝과 $-$ 끝이 겹쳐 상쇄되지만, 양쪽 표면에는 짝을 잃은 전하가 남는다. 이것이 **속박 표면 전하**이며, 그 밀도는
$$
\sigma_b = \vec{P}\cdot\hat{n}
$$
이다($\hat{n}$은 표면의 바깥 법선). 쌍극자를 이루는 전하 $q$가 거리 $\delta$만큼 밀렸다면 표면 넓이 $A$에 걸쳐 두께 $\delta$의 층에 $nqA\delta$의 전하가 드러나므로 $\sigma_b = nq\delta = np = P$이다.

축전기의 양극판(자유 전하 $+\sigma_f$) 쪽 유전체 표면에는 $-\sigma_b$가, 음극판 쪽에는 $+\sigma_b$가 나타난다. 유전체 속의 장은 두 쌍의 면전하가 만든 것이므로
$$
E = \frac{\sigma_f - \sigma_b}{\varepsilon_0} = \frac{\sigma_f - \chi_e\varepsilon_0E}{\varepsilon_0}\quad\Longrightarrow\quad E = \frac{\sigma_f}{\varepsilon_0(1 + \chi_e)} = \frac{E_0}{\kappa}
$$
즉 $\boxed{\kappa = 1 + \chi_e}$이다. 유전체가 장을 약하게 하는 것은 **분극이 만든 속박 전하가 자유 전하를 부분적으로 가리기 때문**이다. 같은 전압에서는 판이 더 많은 자유 전하를 담을 수 있으므로 용량이 커진다. 분극이 고르지 않으면 내부에도 속박 전하가 생기며 그 밀도는 $\rho_b = -\nabla\cdot\vec{P}$이다.

> **💡 개념 확인: 유전체와 도체의 차이**
> 도체에서는 전하가 표면까지 **자유롭게** 움직여 내부 장을 **완전히** 0으로 만든다. 유전체에서는 전하가 분자에 묶인 채 **조금만** 움직여 내부 장을 $1/\kappa$로 **줄일 뿐**이다. 그래서 유전체 속에서는 장이 0이 아니고, 유전체의 양 끝 사이에는 전위차가 있다.

> **🔗 전공 연결: 세포막은 축전기다(약학·수의학)**
> 세포막의 지질 이중층은 두께 수 nm의 얇은 절연층이고, 안팎은 이온이 녹아 있는 전도성 용액이다. 즉 세포막은 **평행판 축전기**다. 생체막의 단위 넓이당 전기용량은 대부분의 세포에서 대략 $1\ \mu\text{F/cm}^2$로 알려져 있다. 23장의 막전위(약 $-70\ \text{mV}$)는 이 축전기에 저장된 전하가 만든다. 연습문제 9에서 보듯, 막전위를 $100\ \text{mV}$ 바꾸는 데 필요한 이온의 수는 세포 속 칼륨 이온 전체의 수만분의 1에 불과하다. 그래서 신경은 이온 농도를 거의 바꾸지 않고도 빠르게 전기 신호를 보낼 수 있다. 신경 신호의 전달 속도와 모양을 다루는 **케이블 이론**에서 막은 저항과 축전기가 이어진 회로로 모형화된다(25장 RC 회로). 축삭을 감싼 **수초**(myelin)는 막을 여러 겹 감아 두께를 늘림으로써 전기용량을 줄여 신호를 빠르게 한다.

> **🔬 최신 연구 노트: 슈퍼커패시터와 에너지 저장**
> **전기 이중층 축전기(electric double-layer capacitor, EDLC)**, 흔히 슈퍼커패시터라 부르는 소자는 예제 24.1의 "불가능"을 두 가지 방법으로 극복한다. 첫째, 전극을 전해질에 담그면 전극 표면의 전하와 반대 부호의 이온이 표면에 달라붙어 **나노미터 수준 두께의 전기 이중층**을 만든다. 이중층이 사실상 간격 $d$가 분자 크기인 축전기가 된다. 둘째, 전극을 활성탄처럼 미세한 구멍이 무수히 뚫린 물질로 만들어 1그램당 수백~수천 $\text{m}^2$의 표면적을 얻는다. $C = \varepsilon A/d$의 분모는 아주 작게, 분자는 아주 크게 만든 셈이다. 화학 반응으로 에너지를 저장하는 리튬이온 배터리(25장)와 달리 이온의 물리적 이동만 일어나므로, 충방전이 빠르고(큰 일률) 수십만 번 이상 반복해도 성능이 거의 떨어지지 않는다. 대신 전해질이 분해되지 않는 범위로 셀 전압이 수 V 이하로 제한되고, 저장 에너지 $\frac{1}{2}CV^2$이 같은 무게의 배터리보다 작다. 그래서 순간적으로 큰 일률이 필요한 곳, 예를 들어 차량의 회생 제동 에너지 회수(28장), 기계 장치의 순간 정전 대비 전원, 배터리와 함께 쓰는 혼합 저장 장치 등에 쓰인다. 전극 소재(그래핀 등 탄소 나노 물질)와 전해질을 개선해 에너지 밀도를 높이는 연구가 활발하다.

> **🐍 파이썬 실습: 유전 상수가 위치에 따라 변하는 축전기**
> 간격 방향으로 유전 상수가 $\kappa(x) = \kappa_1 + (\kappa_2 - \kappa_1)x/d$로 변하는 평행판 축전기는 얇은 층의 직렬 연결이므로 $1/C = \int_0^d dx/(\kappa\varepsilon_0A)$이다. 수치 적분으로 $C$를 구하고, 장 에너지 $\int\frac{1}{2}\kappa\varepsilon_0E^2\,dV$가 $\frac{1}{2}CV^2$과 같은지 확인한다. ★에서 본 대로 판에 수직인 $D$가 간격 전체에서 일정하다는 사실을 쓴다.
> ```python
> import numpy as np
> from scipy.integrate import quad
>
> eps0 = 8.8541878128e-12
> A, d, V = 0.010, 1.0e-3, 100.0          # 극판 넓이(m^2), 간격(m), 전압(V)
> k1, k2 = 2.0, 6.0                       # 양 극판 쪽의 유전 상수
> kappa = lambda x: k1 + (k2 - k1)*x/d     # 간격을 따라 선형으로 변하는 κ(x)
>
> # 직렬 연결된 얇은 층들: 1/C = ∫ dx / (κ(x) ε0 A)
> inv_C, _ = quad(lambda x: 1/(kappa(x)*eps0*A), 0, d)
> C_num = 1/inv_C
> C_exact = eps0*A*(k2 - k1)/(d*np.log(k2/k1))
> print(f"C (수치)   = {C_num*1e12:.2f} pF")
> print(f"C (해석해) = {C_exact*1e12:.2f} pF")
>
> # 장 에너지 ∫ (1/2) κ ε0 E^2 dV 와 (1/2) C V^2 비교
> Q = C_num*V
> D = Q/A                                  # 전기 변위 D는 간격 전체에서 일정
> E = lambda x: D/(kappa(x)*eps0)
> U_field, _ = quad(lambda x: 0.5*kappa(x)*eps0*E(x)**2*A, 0, d)
> print(f"U (장 적분) = {U_field*1e9:.3f} nJ,  CV^2/2 = {0.5*C_num*V**2*1e9:.3f} nJ")
> print(f"E(0) = {E(0):.3e} V/m,  E(d) = {E(d):.3e} V/m")
> ```
> 실행하면 $C = 322.38\ \text{pF}$로 해석해 $\varepsilon_0A(\kappa_2 - \kappa_1)/[d\ln(\kappa_2/\kappa_1)]$과 일치하고, 두 에너지가 모두 $1611.886\ \text{nJ}$로 같다. 장은 $\kappa$가 작은 쪽($x = 0$)에서 $1.82\times10^5\ \text{V/m}$, 큰 쪽에서 $6.07\times10^4\ \text{V/m}$로 정확히 3배 차이 난다. 유전체가 약한 곳에 장이 몰리므로, 고전압 케이블처럼 여러 절연층을 겹쳐 쓰는 설계에서는 이런 곳에서 먼저 절연이 파괴되지 않도록 주의해야 한다.

> **★ 심화: 클라우지우스–모소티 관계**
> 밀도가 높은 물질에서 한 분자가 느끼는 장은 거시적 평균장 $\vec{E}$가 아니라, 그 분자 자신을 뺀 나머지 분자들이 만드는 **국소장**(local field)이다. 분자를 둘러싼 작은 구형 공동을 생각하면 국소장은 $\vec{E}_{\text{loc}} = \vec{E} + \vec{P}/3\varepsilon_0$이 된다(공동 벽의 속박 전하가 만드는 장이 22장 연습문제 11과 같은 방식으로 계산된다). $\vec{P} = n\alpha\vec{E}_{\text{loc}}$와 $\vec{P} = (\kappa - 1)\varepsilon_0\vec{E}$를 연립하면
> $$\frac{\kappa - 1}{\kappa + 2} = \frac{n\alpha}{3\varepsilon_0}$$
> 이다. 이것이 **클라우지우스–모소티 관계**(Clausius–Mossotti relation)로, 거시적 유전 상수와 분자 하나의 분극률을 잇는다. 희박한 기체에서는 $\kappa - 1\ll1$이므로 $\kappa\approx1 + n\alpha/\varepsilon_0$로 단순해진다. 빛의 진동수에서는 $\kappa = n_{\text{굴절}}^2$이므로, 같은 식이 굴절률과 분자 구조를 잇는 로런츠–로렌츠 식(Lorentz–Lorenz equation)이 된다(굴절률은 32장).

## 핵심 정리

| 개념 | 핵심 식 | 비고 |
|---|---|---|
| 전기용량 | $C = Q/V$ | 모양·물질에만 의존 |
| 평행판 | $C = \varepsilon_0A/d$ | 가장자리 효과 무시 |
| 원통형(동축) | $C = 2\pi\varepsilon_0L/\ln(b/a)$ | |
| 구형 / 고립된 구 | $C = 4\pi\varepsilon_0ab/(b - a)$ / $4\pi\varepsilon_0a$ | |
| 병렬 / 직렬 | $C = \sum C_i$ / $1/C = \sum1/C_i$ | 병렬은 같은 $V$, 직렬은 같은 $Q$ |
| 저장 에너지 | $U = Q^2/2C = \frac{1}{2}CV^2 = \frac{1}{2}QV$ | |
| 에너지 밀도 | $u = \frac{1}{2}\varepsilon_0E^2$ (유전체 속 $\frac{1}{2}\kappa\varepsilon_0E^2$) | 장에 저장된 에너지 |
| 유전체 | $C = \kappa C_0$; Q 일정이면 $E = E_0/\kappa$ | $\varepsilon = \kappa\varepsilon_0$ |
| 유전체 속 가우스 법칙 | $\oint\kappa\vec{E}\cdot d\vec{A} = q_{\text{free}}/\varepsilon_0$, $\oint\vec{D}\cdot d\vec{A} = q_{\text{free}}$ | |
| 분극 | $\vec{P} = n\langle\vec{p}\rangle = \chi_e\varepsilon_0\vec{E}$, $\sigma_b = \vec{P}\cdot\hat{n}$ | $\kappa = 1 + \chi_e$ |
