# 집필 지침 (Style Guide)

이 문서는 『입학 전 자습용 일반물리학』의 모든 장이 같은 형식과 수준을 유지하도록 정한 규칙입니다. 새 장을 쓰거나 고칠 때 이 지침을 따릅니다.

## 1. 독자
- 대학 합격 후 입학 전까지 혼자 공부하는 **과학고 출신 신입생**입니다.
- 고교 수준의 미적분과 역학·전자기 기본 개념은 알고 있습니다.
- 대학 일반물리는 다음을 기준으로 삼습니다.
  - 서울대 물리학 1·2와 고급물리학
  - KAIST 일반물리학 I·II
  - 연세대 공학물리학및실험
  - 성균관대·중앙대·건국대 일반물리학
- 목표는 두 가지입니다. ① 1학년 일반물리 시험에서 바로 통하는 실력, ② 아너스(고급) 과정에도 대비할 수 있는 깊이.

## 2. 언어와 표기
- 본문은 **한국어 존댓말이 아닌 교재체**(~이다, ~한다)로 씁니다.
- 물리 용어는 처음 나올 때 한글(영어) 형식으로 쓰고, 굵게 할 때는 `**운동량**(momentum)`처럼 **한글만 굵게** 합니다. `**운동량(momentum)**이`처럼 닫는 `**` 앞이 괄호이고 뒤에 한글이 붙으면 GitHub에서 굵은 글씨가 깨지기 때문입니다. 예: 운동량(momentum).
  - 대학 수업이 영어로 진행되는 경우가 많으므로 영어 용어를 반드시 함께 적습니다.
- 수식은 GitHub 마크다운 수식 문법을 씁니다. 줄 안 수식은 `$...$`, 별도 줄 수식은 `$$...$$`입니다.
- 벡터는 굵은 글씨 $\mathbf{F}$ 또는 $\vec{F}$ 중 **$\vec{F}$로 통일**하고, 단위벡터는 $\hat{x}, \hat{y}, \hat{z}$ 또는 $\hat{i}, \hat{j}, \hat{k}$ 중 **$\hat{i}, \hat{j}, \hat{k}$로 통일**합니다.
- **표 안의 수식에는 `|`를 쓰지 않습니다.** GitHub에서 표 칸이 나뉘어 버리므로 절댓값은 `\lvert x\rvert`로 씁니다.
- **1이 아닌 번호로 시작하는 목록(예: 응용 7번) 앞에는 빈 줄을 둡니다.** 바로 위 줄이 문단이면 목록으로 인식되지 않고 한 문단으로 뭉칩니다.
- 줄 안 수식의 닫는 `$` 앞에는 공백을 두지 않습니다(`$J = $ 일정` ✗ → `$J = \text{일정}$` ✓).
- 단위는 SI를 쓰고, 숫자와 단위 사이는 띄웁니다. 예: $9.8\ \text{m/s}^2$.
- 물리 상수는 CODATA 2018 값을 씁니다(2019 SI 재정의 이후 정의값 포함).

## 3. 장의 구성 (모든 장 공통 틀)
```
# n장 제목
> 대응 교재: Halliday 12판 x장 · Young&Freedman 15판 y장

## 학습 목표            (4~6개)
## 고등학교 물리와 무엇이 다른가   (짧은 도입: 이 장에서 새로 쓰는 수학과 관점)
## n.1 ~ n.k  본문 절      (개념 → 유도 → 예제 순)
   - 예제 n.m (풀이 포함)
   - 박스(아래 5종)를 장마다 적절히 배치
## 핵심 정리             (공식과 개념 요약 표 또는 목록)
## 연습문제              (기본 / 응용 / 도전, 합계 12~20문항)
## 연습문제 답과 힌트      (기본은 답, 응용·도전은 핵심 힌트와 답)
## 영어 용어 정리          (한글 | English 표)
```

### 박스 5종
| 표시 | 이름 | 용도 |
|---|---|---|
| 💡 | 개념 확인 | 짧은 퀴즈나 흔한 오개념 바로잡기 |
| ★ | 심화 | 고급물리학·아너스 수준 내용 (예: 라그랑주 역학, 미분형 맥스웰 방정식). 처음 읽을 때는 건너뛰어도 되는 부분 |
| 🔬 | 최신 연구 노트 | 최근 학계 동향과의 연결 (아래 5절 목록에서 고름) |
| 🔗 | 전공 연결 | 기계공학·약학·수의학 전공 과목과의 연결 (예: 응력 → 고체역학, 확산 → 약물동태학, 초음파 → 수의영상의학) |
| 🐍 | 파이썬 실습 | numpy·matplotlib로 돌아가는 짧은 코드 (30줄 안팎). 반드시 실행해 검증한 코드만 싣기 |

박스는 마크다운 인용문으로 씁니다.
```
> **★ 심화: 라그랑주 역학 맛보기**
> 내용...
```

## 4. 분량과 수준
- 한 장은 대략 A4 12~20쪽 분량을 목표로 합니다(마크다운 25~45 KB).
- 고교에서 배운 내용은 짧게 복습하고, **미적분과 벡터를 써서 다시 유도하는 데** 비중을 둡니다.
- 예제는 장마다 5~8개를 넣습니다. 수치 계산 문제, 개념 문제, 유도 문제를 섞습니다.
- 연습문제의 "도전" 단계는 KAIST·서울대 고급과정 시험 수준을 목표로 합니다.

## 5. 정확성 규칙
- 출처가 확실하지 않은 수치·연도·인물·실험 이야기는 쓰지 않습니다.
- 최신 연구 노트에는 아래처럼 사실관계가 확립된 주제만 씁니다.
  - 2019 SI 재정의(플랑크 상수 $h$, 기본전하 $e$, 볼츠만 상수 $k_B$, 아보가드로 수 $N_A$를 정의값으로 고정)
  - 2015년 LIGO의 중력파 첫 검출과 2017 노벨 물리학상
  - 2020 노벨상(블랙홀), 2019 노벨상(우주론·외계행성)
  - 2022 노벨상: 얽힌 광자 실험과 벨 부등식 위배(Aspect, Clauser, Zeilinger)
  - 2023 노벨상: 아토초 광펄스(Agostini, Krausz, L'Huillier)
  - 2024 노벨상: 인공신경망의 물리학적 기초(Hopfield 네트워크와 Hinton의 볼츠만 머신)
  - 2025 노벨상: 전기회로에서의 거시적 양자 터널링과 에너지 양자화(Clarke, Devoret, Martinis). 초전도 큐비트의 기반
  - 2025년 UN 지정 "세계 양자 과학기술의 해"(양자역학 100주년)
  - 2022년 12월 미국 국립점화시설(NIF)의 핵융합 점화(투입 레이저 에너지보다 많은 핵융합 에너지 방출)
  - GPS의 상대론 보정, MRI·NMR의 원리, 반도체 소자, 리튬이온 배터리, 계산물리와 머신러닝의 활용
