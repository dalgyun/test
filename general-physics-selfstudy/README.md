# 입학 전 자습용 일반물리학

서울대·KAIST·연세대 등 주요 대학의 1학년 일반물리 과정과 교재를 조사해, 입학 전에 혼자 공부할 수 있도록 만든 한국어 교재입니다.

## 먼저 읽을 파일
1. **`00_조사보고서.md`**: 대학별 일반물리 과목, 교재, 강의계획서 조사 결과. 대학별로 어느 장까지 다루는지 비교한 표가 3절에 있습니다.
2. **`01_목차.md`**: 전체 목차(0~40장, 특집 2, 부록 3)와 14주 학습 일정
3. **`chapters/ch00_대학물리_공부법.md`**: 이 책 활용법

- 💡 개념 확인
- ★ 심화(고급물리학·아너스 수준)
- 🔬 최신 연구 노트
- 🔗 전공 연결(기계·약학·수의)
- 🐍 파이썬 실습

## 만든 과정과 품질 관리
1. **조사**: 각 대학 공개 강의계획서 원문과 학사요람을 확인했습니다. 원문이 공개되지 않은 학교는 2차 출처라고 표시했습니다.
2. **설계**: 조사 결과에 따라 목차와 집필 지침을 정했습니다.
3. **집필**: 0~1장과 부록 A·B는 직접 썼고, 나머지 장은 지침과 견본 장(1장)을 따라 보조 에이전트가 나눠 썼습니다.
4. **독립 검수**: 집필하지 않은 별도 검수 에이전트가 모든 장을 다시 읽었습니다.
   - 예제와 연습문제 답을 파이썬으로 처음부터 다시 계산했습니다.
   - 🔬 박스의 연도·인물·수치를 확인하고, 불확실한 표현은 완화했습니다.
   - 장 번호 참조와 원서 대응 장을 확인했습니다.
   - 실제로 고친 내용: 계산 오류, 부호 오류, 문제와 답의 조건 불일치, 사실관계 과장, GitHub에서 표가 깨지는 수식 등
5. **자동 점검**: 모든 장의 필수 구성 요소와 박스 종류를 확인했고, 실린 파이썬 코드는 모두 실행했습니다.

> 그래도 사람이 감수한 교재가 아니므로, 공부하다가 이상한 부분이 보이면 원서(Halliday, Young & Freedman)의 대응 장과 대조해 보시기 바랍니다. 각 장 머리에 대응 장 번호가 있습니다.
